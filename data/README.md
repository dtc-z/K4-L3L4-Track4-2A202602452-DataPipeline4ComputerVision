# Dữ liệu của lab

Thư mục này **chưa có dữ liệu**: chạy `python3 scripts/fetch_data.py` từ thư mục gốc của lab. Script tải `day09-data.zip` theo đường dẫn trong `MANIFEST.json`, kiểm tra SHA-256, giải nén vào đây rồi xóa archive. Sau đó chạy `python3 scripts/check_data.py`.

Dữ liệu được cắt từ bộ L2D-v3 của Yaak (Apache 2.0): https://huggingface.co/datasets/yaak-ai/L2D-v3
